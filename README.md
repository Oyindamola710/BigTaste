

# Big Taste - E-Commerce Product Landing Page

## Overview

**Big Taste** is a one-page e-commerce product landing page built using HTML, CSS, and JavaScript. This project delivers a visually appealing, responsive, and interactive design intended for showcasing jewelry items. It features a dynamic user experience with several engaging UI components to simulate a real-world e-commerce platform.

---

## Features

- **Fixed Navigation Bar**  
  Includes:
  - Sign In/Login button  
  - Shopping cart icon  
  - Wholesale page link  

- **Featured Product Section**  
  Displays various realistic jewelry items (e.g., wristwatches, earrings, necklaces) with:
  - High-quality placeholder images  
  - Product names and prices  

- **Customer Reviews Section**  
  - Filler content for customer reviews and star ratings  
  - Showcases social proof for prospective customers  

- **Perks for New Customers**  
  - Highlighted statement offering **free shipping** and **free gifts** for first-time buyers  

- **Footer Section**  
  Includes links to:
  - Blog  
  - FAQ  
  - Privacy Policy  
  - "Contact Us" button triggering a modal with:
    - Contact form  
    - Customer support details  

- **Interactive Components**
  - **Pop-up Rating Survey** on page load  
  - **Search Bar** to look up specific jewelry items  
  - **Language & Currency Sidebar** for internationalization preferences  

---

## Technologies Used

- **HTML5** – Semantic structure of the page  
- **CSS3** – Styling, layout, and responsive design  
- **JavaScript** – Interactivity, modals, pop-ups, and dynamic content  

---

## Setup Instructions

1. Clone the repository or download the HTML file.
2. Open the `index.html` file in any modern web browser.
3. Explore the full functionality directly in your browser—no additional setup required.
